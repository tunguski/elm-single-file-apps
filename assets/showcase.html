Elm · single-file · offline

Single-File Apps

Six little apps. Each is one self-contained HTML file that stores its own data inside itself — edit, then press Ctrl+S to save.

How it works

Your data lives in the file

There's no server and no database. Each app serializes its state into a block inside its own HTML, so the file is the document. Copy it, email it, back it up — it's yours.

Save with Ctrl+S

In Chrome & Edge the app writes back to the same file in place. Elsewhere it downloads a fresh copy you save over. A badge shows unsaved changes.

Offline & installable

Everything is inlined, so every app works with no network — open it straight from disk. Served over HTTPS, each one is an installable PWA with its own icon.

Built with the elm-lang compiler · the spreadsheet reuses the elm-spreadsheet engine.
